Payroll Export CSV Schema

This schema aligns with industrial ERP and payroll integration standards (ADP, Workday, SAP, Zoho Payroll). Each row aggregates one employee's shift performance across the selected date range.

CSV Column Name Data Type Description Payroll Mapping
Employee ID Integer Database primary key Internal Foreign Key
Employee Code String Workforce badge code (e.g. EMP-1042) Payroll Employee Number
Full Name String Enrolled employee name Payee Name
Department String Assigned organizational unit Cost Center / Department
Site String Branch / Office work site Tax Jurisdiction / Location
Regular Hours Float (2 dec) Net shift hours worked minus lunch break Standard Base Pay Hours
Overtime Hours Float (2 dec) Hours logged past scheduled shift end 1.5x / 2.0x OT Multiplier
Total Hours Float (2 dec) Regular + Overtime gross work time Total Time Worked
Late Days Integer Count of check-ins past grace period Punctuality Deduction Policy
Flagged Events Integer Geofence violations or liveness flags HR Disciplinary / Audit Hold
Total Work Days Integer Distinct active work days in period Attendance Bonus / Per Diem
